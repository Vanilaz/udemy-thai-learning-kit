# คู่มือตั้งค่าซับไทยบนเว็บ Udemy

เอกสารนี้ตอบคำถามว่า **"เปิดเว็บเรียนแล้วจะมีซับไทยขึ้นเลยไหม"**

คำตอบสั้น: **ได้ครับ แต่มีสองทาง และคุณภาพต่างกันมาก**

---

## ภาพรวม: สองทาง เลือกตามสถานการณ์

| | ทาง A — Extension แปลสด | ทาง B — ซับของเราเอง |
|---|---|---|
| **ซับขึ้นบนวิดีโอ Udemy** | ใช่ | ใช่ |
| **เตรียมล่วงหน้า** | ไม่ต้อง | ต้อง (ทำครั้งเดียวต่อบทเรียน) |
| **คุณภาพศัพท์เทคนิค** | ปานกลาง — แปลเครื่องซ้อนถอดเสียงเครื่อง | สูง — AI เข้าใจบริบทโปรแกรมมิ่ง |
| **แก้คำที่ถอดเสียงผิด** | ไม่แก้ แปลคำผิดตามตรง | แก้ให้ตามบริบท |
| **ได้สรุปบทเรียน + คลังศัพท์** | ไม่ได้ | ได้ |
| **เวลาที่ใช้** | 0 | ~1-3 นาทีต่อบทเรียน |

**แนะนำให้ใช้ทั้งคู่:** ทาง A เป็นค่าเริ่มต้นสำหรับดูทั่วไป แล้วใช้ทาง B เฉพาะบทที่สำคัญหรือฟังไม่เข้าใจ

---

## ทาง A — Extension แปลสด (ติดตั้ง 5 นาที ใช้ได้ทันที)

ใช้เมื่อ: อยากเปิดเรียนได้เลย ไม่อยากเตรียมอะไร

### ตัวเลือก

| Extension | จุดเด่น |
|---|---|
| [Udemy Dual Subtitles](https://chromewebstore.google.com/detail/udemy-dual-subtitles-subt/mpedooclpiggpfamidjeemfjoeakebce) | แสดงอังกฤษ + ไทยพร้อมกัน รองรับ fullscreen |
| [Udemy Subtitles Translate](https://chromewebstore.google.com/detail/udemy-subtitles-translate/kpemkpeelipeamonllmocgnjbbhafddg) | รองรับ 145+ ภาษา ลากตำแหน่งกล่องซับได้ |
| [Video CC Translator](https://chromewebstore.google.com/detail/video-cc-translator/fhbpmacbgklobobcieiaoibpjhdnmcfn) | ใช้ได้ทั้ง Udemy, Udacity, YouTube |

### ขั้นตอน

1. ติดตั้ง extension จากลิงก์ข้างบน
2. เปิดวิดีโอบทเรียนใน Udemy
3. **เปิดซับอังกฤษก่อน** — กดปุ่ม `CC` แล้วเลือก English
   ข้อนี้สำคัญมาก extension พวกนี้ทำงานโดยอ่านซับอังกฤษที่กำลังแสดงอยู่แล้วแปล
   ถ้าไม่เปิด CC จะไม่มีอะไรให้มันแปล
4. กดไอคอน extension แล้วตั้งภาษาปลายทางเป็น **ไทย**
5. เลือกโหมด **dual / bilingual** ถ้ามี

### ตั้งค่าที่แนะนำ

- **เปิดโหมดสองภาษาเสมอ** — เวลาคำแปลไทยอ่านแล้วงง คุณเหลือบดูอังกฤษเทียบได้ทันที
  และคุณจะซึมซับศัพท์อังกฤษไปด้วยโดยไม่ต้องตั้งใจ
- **ขยายขนาดฟอนต์** ถ้าอ่านไม่ทัน
- **ลดความเร็ววิดีโอเป็น 0.75x** ในบทที่ยาก ซับจะตามทัน สมองก็ตามทัน

### ข้อจำกัดที่ต้องรู้

ซับจากทาง A คือ **แปลด้วยเครื่อง ซ้อนบน ถอดเสียงด้วยเครื่อง** — error สองชั้นทบกัน

ตัวอย่างที่เจอบ่อย: ผู้สอนพูดว่า "async" แต่ระบบถอดเสียงได้เป็น "a sink"
แล้วตัวแปลก็แปล "a sink" เป็น "อ่างล้างจาน" อย่างซื่อสัตย์

**อย่าเชื่อซับ 100%** ถ้าประโยคไหนอ่านแล้วไม่สมเหตุสมผลกับบริบทโค้ด ให้ดูบรรทัดอังกฤษ
นี่คือเหตุผลที่โหมดสองภาษาสำคัญ

## ทาง B — ใช้ซับที่เราสร้างเอง (คุณภาพสูงกว่ามาก)

ใช้เมื่อ: บทเรียนสำคัญ ศัพท์เทคนิคเยอะ หรือทาง A แปลออกมาแล้วงง

หลักการ: สร้างไฟล์ `.srt` ภาษาไทยด้วยเครื่องมือในโปรเจกต์นี้ แล้วใช้ extension
อีกตัวโหลดไฟล์นั้นขึ้นไปแสดงบนวิดีโอ Udemy

### ขั้นที่ 1 — สร้างไฟล์ซับ

ดูขั้นตอนเต็มใน [README](../README.md) สรุปสั้น:

```bash
# 1. ก๊อป transcript จาก Udemy วางในไฟล์ courses/<ชื่อคอร์ส>/<ชื่อบท>.txt
# 2. เตรียม
python -m udemy_th prepare courses/my-course/05-closures.txt
# 3. แปลอัตโนมัติ
python -m udemy_th translate work/my-course/05-closures
# 4. สร้างไฟล์ซับ
python -m udemy_th build work/my-course/05-closures
```

ได้ไฟล์ที่ `out/my-course/05-closures/`:
- `05-closures.dual.srt` — อังกฤษบน ไทยล่าง **(แนะนำ)**
- `05-closures.th.srt` — ไทยอย่างเดียว

### ขั้นที่ 2 — โหลดไฟล์ขึ้นวิดีโอ

ติดตั้ง extension ที่โหลดไฟล์ซับเองได้ตัวใดตัวหนึ่ง:

| Extension | หมายเหตุ |
|---|---|
| [+Sub](https://chromewebstore.google.com/detail/+sub/lpobdmdfgjokempajoobgfdnhjbjlnpm) | รองรับ .srt, .vtt, .ass, .ssa ปรับ sync ได้ |
| [Video Subtitle Overlay](https://chromewebstore.google.com/detail/video-subtitle-overlay/jdejdopkibalhahmfacfmfepeconknnk) | โหลด .srt จากเครื่อง ใช้ได้กับวิดีโอทุกเว็บ |
| [Substital](https://chromewebstore.google.com/detail/substital-add-subtitles-t/kkkbiiikppgjdiebcabomlbidfodipjg) | ลากไฟล์ .srt วางได้ ปรับ sync/สี/ขนาดได้ |

จากนั้น:

1. เปิดวิดีโอบทเรียนใน Udemy
2. กดไอคอน extension แล้วเลือกโหลดไฟล์ `.srt` ที่เราสร้าง
3. **ปิดซับ CC ของ Udemy** เพื่อไม่ให้ซับซ้อนกันสองชั้น
4. ถ้าซับไม่ตรงจังหวะ ใช้ปุ่มปรับ sync (offset) ใน extension เลื่อนให้ตรง

> **หมายเหตุ:** extension เหล่านี้เป็นของบุคคลที่สาม หน้าตาเมนูอาจเปลี่ยนตามเวอร์ชัน
> ขั้นตอนข้างบนเป็นภาพรวม ไม่ใช่ชื่อปุ่มเป๊ะๆ ให้ดูเมนูจริงในตัวที่คุณเลือกติดตั้ง

## แก้ปัญหาที่เจอบ่อย

**ซับเป็นภาษาต่างดาว / สี่เหลี่ยม**
ไฟล์ `.srt` ถูก player อ่านเป็น encoding ผิด สร้างใหม่ด้วย:
```bash
python -m udemy_th build work/my-course/05-closures --bom
```
(ใช้เมื่อเปิดใน VLC/PotPlayer บนวินโดวส์ ส่วน extension ในเบราว์เซอร์มักไม่ต้องใช้)

**Extension ไม่แสดงอะไรเลย (ทาง A)**
เกือบทุกครั้งเกิดจากยังไม่ได้เปิดซับ `CC` ของ Udemy — เปิดก่อน แล้ว refresh หน้า

**ซับไม่ตรงกับเสียง (ทาง B)**
ใช้ปุ่มปรับ sync/offset ใน extension เลื่อนหน้า-หลังทีละ 0.5 วินาที
ถ้าเพี้ยนมากตั้งแต่ต้น แปลว่า transcript ที่ก๊อปมาไม่ครบตั้งแต่บรรทัดแรก ให้ก๊อปใหม่

**บทเรียนไม่มีซับ CC ให้เปิดเลย**
ทาง A ใช้ไม่ได้ ต้องใช้ทาง B แต่ต้องถอดเสียงเองก่อน (Whisper) ซึ่งอยู่นอกขอบเขต
เครื่องมือชุดนี้ — บอกผมได้ถ้าอยากให้เพิ่มส่วนนี้

## ข้อควรทราบ

ไฟล์ซับที่สร้างขึ้นมีไว้ใช้ประกอบการเรียนของคุณเองในคอร์สที่คุณซื้อแล้ว
เก็บไว้ในเครื่อง ไม่ควรแจกจ่ายต่อ เพราะเนื้อหาบทเรียนเป็นลิขสิทธิ์ของผู้สอน
