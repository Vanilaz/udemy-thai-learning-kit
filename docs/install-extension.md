# ติดตั้ง Extension — ทำครั้งเดียว ใช้ได้ตลอด

เป้าหมาย: เปิดวิดีโอใน Udemy แล้วมีซับไทยขึ้นเอง ไม่ต้องรันคำสั่งอะไรอีก

ใช้เวลาติดตั้งประมาณ 3 นาที ทำครั้งเดียวจบ

---

## Extension นี้ทำอะไรให้

เมื่อคุณเปิดบทเรียน มันจะเช็คให้อัตโนมัติว่า:

| สถานการณ์ | สิ่งที่เกิดขึ้น |
|---|---|
| บทนี้**มีซับไทยของ Udemy อยู่แล้ว** | บอกคุณว่ามีอยู่แล้ว — กด CC เลือกไทยได้เลย ไม่แปลซ้ำให้เสียเวลา |
| บทนี้**ไม่มีซับไทย** แต่มีอังกฤษ | ดึงซับอังกฤษมาแปลด้วย AI แล้วแสดงทับบนวิดีโอ |
| บทนี้ไม่มีซับเลย | แจ้งว่าทำอะไรไม่ได้ |

คอร์สจำนวนมากมีซับไทยให้อยู่แล้ว (บางคอร์สเป็นแบบคนแปล คุณภาพดีกว่า AI)
Extension จะไม่ไปยุ่งกับกรณีนั้น — มันมีไว้อุดช่องว่างเฉพาะบท/คอร์สที่ไม่มี

---

## ขั้นที่ 1 — ติดตั้ง Extension เข้า Chrome

1. เปิด Chrome พิมพ์ที่ช่อง address bar: **`chrome://extensions`** แล้ว Enter
2. เปิดสวิตช์ **Developer mode** (โหมดนักพัฒนา) มุมขวาบน
3. กดปุ่ม **Load unpacked** (โหลดที่แตกไฟล์แล้ว)
4. เลือกโฟลเดอร์ **`F:\Project\Udemy\extension`**
5. จะเห็นการ์ด "Udemy ซับไทย (AI)" โผล่ขึ้นมา — เสร็จแล้ว

> **หลังจากผมแก้โค้ดทุกครั้ง** ต้องกดปุ่มรีเฟรช (วงกลมลูกศร) บนการ์ดนี้
> แล้วรีเฟรชหน้า Udemy ด้วย ไม่งั้น Chrome ยังใช้โค้ดเวอร์ชันเก่า

> ปักหมุดไอคอนไว้ให้เห็นง่าย: กดไอคอนรูปต่อจิ๊กซอว์บนแถบเครื่องมือ Chrome
> แล้วกดหมุดข้าง "Udemy ซับไทย"

---

## ขั้นที่ 2 — เปิดเซิร์ฟเวอร์แปล

ดับเบิลคลิก **`start-server.cmd`** ในโฟลเดอร์ `F:\Project\Udemy`

หน้าต่างดำจะเปิดขึ้นและค้างไว้แบบนี้:

```
==========================================================
  Udemy TH — เซิร์ฟเวอร์แปลซับ พร้อมทำงาน
==========================================================
  ที่อยู่ : http://127.0.0.1:8765
```

**เปิดค้างไว้ระหว่างนั่งเรียน** ปิดได้เมื่อเลิกเรียน (กดปิดหน้าต่าง หรือ Ctrl+C)

ครั้งหน้าที่จะเรียน ก็แค่ดับเบิลคลิกไฟล์นี้อีกครั้ง

> ถ้าเรียนแต่คอร์สที่มีซับไทยอยู่แล้ว ไม่ต้องเปิดเซิร์ฟเวอร์ก็ได้
> Extension จะบอกคุณเองว่าบทนั้นมีซับไทยแล้ว

---

## ขั้นที่ 3 — เรียนได้เลย

1. เปิดวิดีโอบทเรียนใน Udemy
2. **ไม่ต้องกด CC** — extension ถามรายการซับจาก Udemy โดยตรง
3. รอสักครู่ (ตัวเล่นวิดีโอของ Udemy ใช้เวลาโหลดราว 10-15 วินาที) จะมีข้อความสถานะขึ้นบนวิดีโอ
4. ถ้าต้องแปล จะขึ้นว่า *"กำลังแปล ... บรรทัดเป็นไทย"* แล้วซับไทยจะขึ้นตามจังหวะเสียง

**ครั้งแรกของแต่ละบท** ใช้เวลาแปลประมาณ 30 วินาที - 2 นาที ขึ้นกับความยาว
**ครั้งต่อไป** ขึ้นทันที เพราะเก็บ cache ไว้แล้ว

---

## ปุ่มตั้งค่า

กดไอคอน extension บนแถบเครื่องมือ:

| ตัวเลือก | ความหมาย |
|---|---|
| แสดงซับไทย | เปิด/ปิดซับของเรา |
| แสดงอังกฤษด้วย | แสดง 2 บรรทัด อังกฤษเล็กบน ไทยใหญ่ล่าง |
| แปลบทเรียนนี้ใหม่ | ล้างแล้วแปลใหม่ ใช้เมื่อคำแปลเพี้ยน |

แนะนำให้เปิด **"แสดงอังกฤษด้วย"** ไว้ เพราะถ้าประโยคไหนอ่านแล้วงง
คุณเหลือบดูต้นฉบับเทียบได้ทันที และได้ฝึกภาษาอังกฤษไปในตัว

---

## แก้ปัญหา

**ไม่มีอะไรขึ้นบนวิดีโอเลย**
เปิด DevTools (กด F12) ไปแท็บ Console แล้วมองหาบรรทัดที่ขึ้นต้นด้วย `[udth]`
- ถ้าไม่มีเลย → extension ยังไม่ทำงาน กดรีเฟรชการ์ดที่ `chrome://extensions` แล้วรีเฟรชหน้า
- ถ้าเห็น `รอตัวเล่นวิดีโอ ...` ค้าง → วิดีโอยังโหลดไม่เสร็จ รอต่ออีกหน่อย

**ขึ้นว่า "ยังไม่ได้เปิดเซิร์ฟเวอร์แปล"**
ดับเบิลคลิก `start-server.cmd` แล้วรีเฟรชหน้า Udemy

**ขึ้นว่า "บทนี้มีซับไทยของ Udemy อยู่แล้ว"**
ไม่ใช่ปัญหา — กดปุ่ม CC ในตัวเล่นวิดีโอ แล้วเลือกภาษาไทย จะได้ซับที่ดีกว่า AI แปล

**ขึ้นว่า "บทนี้ไม่มีคำบรรยายอังกฤษให้แปล"**
บทเรียนนั้นไม่มีซับต้นฉบับเลย ต้องถอดเสียงเองก่อน (Whisper) ซึ่งอยู่นอกขอบเขต
เครื่องมือชุดนี้ — บอกผมได้ถ้าอยากให้เพิ่มส่วนนี้

**เห็นซับซ้อนกันสองชั้น**
ปิดซับ CC ของ Udemy (กด CC เลือก "ปิด") — extension วาดซับเองอยู่แล้ว

**ซับไม่ตรงจังหวะเสียง**
ไม่ควรเกิด เพราะเวลาดึงมาจากไฟล์คำบรรยายต้นฉบับของ Udemy โดยตรง
(ทดสอบเทียบกับซับจริงที่นาทีที่ 1, 3, 6, 8 แล้ว ตรงทุกจุด)

## ทำงานยังไง (สำหรับคนอยากรู้)

```
เปิดหน้าบทเรียน
   │
   ├─► ถาม Udemy API ว่าบทนี้มีซับภาษาอะไรบ้าง
   │      │
   │      ├─ มีไทยแล้ว ──► บอกคุณ แล้วหยุด (ไม่แปลซ้ำ)
   │      │
   │      └─ ไม่มีไทย ──► ดึงไฟล์ซับอังกฤษ (WebVTT) มาทั้งไฟล์
   │                            │
   ▼                            ▼
แสดงซับไทยทับวิดีโอ  ◄──  เซิร์ฟเวอร์ในเครื่องคุณ (127.0.0.1)
      ▲                            │
      └──── cache บนดิสก์ ◄──── AI แปล + ใช้คลังศัพท์เดิม
```

**ทำไมต้องถาม API แทนการอ่านซับจากหน้าเว็บ:** ทดสอบกับหน้าจริงแล้วพบว่า Udemy
ไม่ได้ใช้ TextTrack มาตรฐานของ HTML5 (`video.textTracks` ว่างเปล่าทั้งที่ซับกำลังแสดงอยู่)
มันโหลดไฟล์ WebVTT มาวาดเอง แถมยังล้าง performance buffer ทิ้ง การไปไล่ดักไฟล์
จึงไม่น่าเชื่อถือ ส่วนการถาม API ได้คำตอบแน่นอนทุกครั้ง และได้ซับทั้งบทตั้งแต่วินาทีแรก

ข้อความบทเรียนถูกส่งไปที่เครื่องคุณเองเท่านั้น (127.0.0.1 คือเครื่องคุณ)
แล้วส่งต่อไปให้ AI แปล เหมือนตอนคุณพิมพ์ถาม AI ปกติ

คำแปลถูกเก็บใน `cache/` ส่วนศัพท์เทคนิคสะสมใน `glossary/glossary.json`
ทำให้บทเรียนหลังๆ ใช้คำแปลเดียวกับบทแรกๆ อย่างสม่ำเสมอทั้งคอร์ส

ไฟล์ทั้งหมดอยู่ในเครื่องคุณ ใช้ประกอบการเรียนคอร์สที่คุณซื้อแล้ว ไม่ควรแจกจ่ายต่อ
