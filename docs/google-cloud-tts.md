# ตั้งค่าเสียงพากย์ Google Cloud Chirp 3 HD

1. สร้าง Google Cloud project และเปิด **Cloud Text-to-Speech API**
2. สร้าง service account ที่มีสิทธิ์ใช้งาน Text-to-Speech แล้วดาวน์โหลด JSON key
3. เก็บ JSON key ไว้นอกโฟลเดอร์โปรเจกต์ แล้วตั้ง environment variable ใน Command Prompt:

   ```cmd
   set GOOGLE_APPLICATION_CREDENTIALS=C:\secure\google-tts-key.json
   ```

   หากต้องการให้ใช้งานทุกครั้ง ให้ตั้งตัวแปรนี้ใน Windows Environment Variables
   แล้วเปิด `start-server.cmd` ใหม่
4. ติดตั้ง dependency หนึ่งครั้ง:

   ```cmd
   python -m pip install -r requirements.txt
   ```
5. เปิด server, reload extension ที่ `chrome://extensions`, แล้วเปิดสวิตช์
   **พากย์ไทยด้วยเสียง HD** จาก popup ของ extension

## เรื่องโควต้า — อ่านก่อนใช้

เสียงและตัวนับถูกเก็บใต้ `cache/audio/` ในเครื่อง cue เดิมจึงไม่ถูกส่งไป Google ซ้ำ
และเซิร์ฟเวอร์จะ**ปฏิเสธไม่ส่งคำขอเลย**เมื่อถึงเพดาน 900,000 ต่อเดือน (โควต้าฟรีคือ 1,000,000)

### นับเป็น "ไบต์" ไม่ใช่ "ตัวอักษร"

[เอกสาร quota ของ Google](https://docs.cloud.google.com/text-to-speech/quotas) ระบุขนาดเป็นไบต์
และเขียนไว้ชัดว่าบางภาษา 1 ตัวอักษรกินหลายไบต์ **ภาษาไทยใน UTF-8 คือ 3 ไบต์ต่อตัวอักษร**

ตัวนับในเครื่องจึงนับไบต์ ไม่ใช่ตัวอักษร ถ้านับตัวอักษรจะต่ำกว่าความจริง 3 เท่า
แล้วทะลุโควต้าฟรีไปโดยที่ตัวกันยังไม่ทำงาน

แปลว่า 900,000 ไบต์ ≈ **300,000 ตัวอักษรไทย** ถ้าปรากฏว่า Google คิดตามตัวอักษรจริงๆ
เพดานนี้ก็แค่มาถึงเร็วกว่าที่ควร — ซึ่งเป็นด้านที่ผิดแล้วไม่เสียเงิน

ปรับเพดานได้ก่อนเปิด server:

```cmd
set UDTH_TTS_MONTHLY_LIMIT=850000
```

### สิ่งที่ตัวนับนี้กันไม่ได้

ตัวนับอยู่ในเครื่อง ไม่ได้ถามยอดจริงจาก Google จึงมีช่องโหว่ที่ควรรู้:

- **ลบโฟลเดอร์ `cache/` แล้วตัวนับกลับเป็นศูนย์** แต่ยอดจริงฝั่ง Google ไม่ได้รีเซ็ตด้วย
- **ไม่รู้จักการใช้งานจากที่อื่น** ถ้า project เดียวกันถูกใช้จากเครื่องอื่นหรือแอปอื่น
- **เดือนนับตามเวลาเครื่อง** ซึ่งอาจไม่ตรงกับรอบบิลของ Google เป๊ะ

**ถ้าไม่อยากเสี่ยงเลย ให้ตั้ง budget alert ใน Google Cloud Console ด้วย** — นั่นคือตัวเดียว
ที่ดูยอดจริง หรือใช้ `edge` แทนซึ่งไม่มีโควต้าและไม่มีบัญชีให้ต้องเฝ้า ดู [voices.md](voices.md)
