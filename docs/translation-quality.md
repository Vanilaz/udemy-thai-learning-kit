# แหล่งซับ คุณภาพคำแปล และ 9router

## เลือกซับจากอะไร

ส่วนขยายแปลเป็นภาษาไทย โดยเลือกซับ Udemy ที่ตรงกับภาษาที่คอร์สระบุก่อน แม้เป็นซับอัตโนมัติ
ถ้าไม่มี จะใช้ซับอังกฤษสำรองและแจ้งว่าอาจผ่านการแปลมาแล้ว ไม่สุ่มเลือกภาษาอื่น
ภาษาที่เลือกในแผงถอดความของ Udemy ไม่ได้เปลี่ยนภาษาต้นทางที่ส่วนขยายเลือกจากรายการซับ

เปิดเมนู **ไทย** บนเครื่องเล่นเพื่อดูภาษา ชนิด CC/อัตโนมัติ และสถานะซับสำรอง
CC เป็นป้ายชนิดซับ ไม่ใช่หลักฐานว่ามีคนตรวจความถูกต้องแล้ว
ข้อความ **ตรงกับภาษาที่คอร์สระบุ** หมายถึงเทียบกับข้อมูลคอร์ส ไม่ใช่การตรวจภาษาจากเสียง
ถ้าไม่มีซับที่ใช้ได้ ส่วนขยายไม่สามารถสร้างซับจากเสียงให้อัตโนมัติได้

โมเดลรับต้นฉบับได้หลายภาษา รวมทั้งหลายภาษาปนกัน แต่คุณภาพขึ้นกับโมเดลและภาษานั้น
บทความใน Section ใช้โหมดเอกสาร รักษาลิงก์และรูปแบบ และข้ามข้อความในโค้ด

## เชื่อมต่อ 9router บนเครื่อง

คัดลอก `.env.example` เป็น `.env` หากยังไม่มี แล้วตั้งค่าตัวอย่างนี้:

```ini
UDTH_LLM_URL=http://localhost:20128/v1
UDTH_LLM_KEY=your-router-key
# ใส่ ID จริงจากรายการโมเดลของ router หรือเว้นไว้ให้เลือกตัวแรกจาก /models
#UDTH_LLM_MODEL=your-model-id
UDTH_LLM_PARALLEL=3
UDTH_LLM_REVIEW=1
```

อย่าใช้ key ตัวอย่างแทน key จริง และอย่านำ `.env` ขึ้น Git หรือส่งให้คนอื่น
หากต้องการโมเดลเดิมทุกครั้ง ควรกำหนด `UDTH_LLM_MODEL` เพราะลำดับจาก `/models` อาจเปลี่ยนได้
รองรับ gateway แบบ OpenAI Chat Completions โดยเรียก `/v1/models` และ `/v1/chat/completions`

`UDTH_LLM_FALLBACK_MODEL` ใช้กำหนดโมเดลสำรองใน gateway เดียวกันได้
เมื่อ endpoint ติดต่อไม่ได้หรือเกิดข้อผิดพลาดชั่วคราวที่รองรับ ระบบจึงสลับไป agy
การยืนยันตัวตนผิด เช่น HTTP 401/403 จะแจ้งข้อผิดพลาดแทนการสลับเพื่อซ่อนปัญหา

## รอบตรวจอัตโนมัติทำอะไร

เส้นทาง API แปลแต่ละช่วงแล้วตรวจข้อความซ้ำก่อนส่งให้ผู้เรียน ใช้ทั้งวิดีโอและบทความ
คุณไม่ต้องอ่านภาษาต้นฉบับหรือแก้ศัพท์เอง รอบตรวจใช้โมเดล API ตัวเดียวกับรอบแปล
พร้อมต้นฉบับ คำแปลรอบแรก และศัพท์ที่เกี่ยวข้องของคอร์ส

- ตรวจความหมาย คำตกหล่น ศัพท์ และภาษาไทยที่ติดขัด
- หากต้นฉบับกำกวม ให้คงศัพท์พร้อมระบุว่า **ต้นฉบับไม่ชัดเจน** แทนการเดาชื่อเทคโนโลยีหรือเวอร์ชัน
- โปรแกรมตรวจว่าหัวข้อและหมายเลขบรรทัดครบ ตัวเลขไม่เปลี่ยน และ inline code/URL ไม่หาย
- ถ้ารอบตรวจล้มเหลวหรือผลไม่ผ่านการตรวจรูปแบบ ใช้คำแปลรอบแรกและแจ้งใน log เซิร์ฟเวอร์

การตรวจข้อความไม่ได้รับประกันความถูกต้องทั้งหมด และไม่ได้ฟังเสียงหรือเปรียบเทียบกับภาพสไลด์
เส้นทางสำรอง agy และ Claude ไม่ได้ใช้รอบตรวจ API นี้
รอบตรวจเพิ่มคำขอ API และเวลารอ ปิดได้ด้วย `UDTH_LLM_REVIEW=0` แล้วเปิดเซิร์ฟเวอร์ใหม่

## คลังศัพท์ประจำคอร์ส

เซิร์ฟเวอร์เก็บศัพท์ที่เรียนรู้ใน `glossary/by-course/<course-hash>.json`
บทถัดไปจะใช้ศัพท์ที่เกี่ยวข้องจากคอร์สเดียวกันเพื่อช่วยให้คำแปลสม่ำเสมอ
เปิด **ศัพท์ประจำคอร์ส** ในเมนูเครื่องเล่นเพื่ออ่านคำไทยและคำอธิบาย แสดงได้สูงสุด 200 คำ
ไม่ต้องกรอกหรือแก้คลังศัพท์ด้วยตนเอง

คลังรวมเก่า `glossary/glossary.json` ไม่ถูกนำมาปนหรือย้ายอัตโนมัติ
CLI และคำสั่ง `glossary --tidy`/ส่งออกยังทำงานกับคลังรวมเดิม ไม่ใช่ทุกไฟล์ใน `by-course`
ศัพท์ที่โมเดลเรียนรู้ยังอาจผิดได้ จึงไม่ควรถือว่าคลังนี้ผ่านการรับรองจากผู้สอน

## ใช้กับบทที่แปลไว้แล้ว

1. ปิดแล้วเปิด `start-server.cmd` ใหม่
2. กด Reload ที่การ์ดส่วนขยายใน `chrome://extensions` หรือ `edge://extensions`
3. รีเฟรชหน้า Udemy/YouTube
4. กด **แปลใหม่** เมื่อต้องการให้บทที่มีแคชเดิมผ่านรอบตรวจและสร้างคลังศัพท์แยกคอร์ส

ระบบเก็บแคชเดิมไว้ ไม่ลบหรือส่งคำขอแปลบทเก่าทั้งหมดโดยอัตโนมัติ
ถ้าหน้าจอขึ้น **กำลังโหลดเสียงพากย์** หลังแปลเสร็จ นั่นคือการรอโมเดลเสียง แยกจากงานแปล
เครื่องที่ VRAM น้อยสามารถใช้เสียง Edge และตั้ง `UDTH_PRELOAD=off` เพื่อลดการโหลดโมเดล GPU ล่วงหน้า
