# Udemy TH — เครื่องมือช่วยเรียนคอร์ส Udemy เป็นภาษาไทย

แปลง transcript ภาษาอังกฤษของบทเรียน Udemy ให้เป็น **ซับไทย + สรุปบทเรียน + คลังศัพท์เทคนิค**
โดยแปลด้วย AI ที่เข้าใจบริบทโปรแกรมมิ่ง ไม่ใช่แปลคำต่อคำ

## เริ่มตรงนี้ — ใช้แบบนั่งเรียนปกติ

**[ติดตั้ง Chrome Extension](docs/install-extension.md)** ← วิธีที่แนะนำ

เปิดวิดีโอใน Udemy แล้วซับไทยขึ้นเอง ไม่ต้องรันคำสั่งอะไร ไม่ต้องกด CC

Extension จะเช็คให้ก่อนว่าบทนั้นมีซับไทยของ Udemy อยู่แล้วหรือไม่:
- **มีอยู่แล้ว** → บอกคุณให้กด CC เลือกไทย (ของ Udemy ดีกว่า ไม่แปลซ้ำให้เสียเวลา)
- **ไม่มี** → ดึงซับอังกฤษมาแปลด้วย AI แล้วแสดงทับบนวิดีโอ

ส่วนที่เหลือของเอกสารนี้เป็นโหมด CLI สำหรับสร้างไฟล์ `.srt` และสรุปบทเรียนเก็บไว้อ่าน

## เครื่องมือนี้ไม่ทำอะไร

- ❌ ไม่ดาวน์โหลดวิดีโอจาก Udemy
- ❌ ไม่ถอดเสียงจากวิดีโอ (บทเรียนต้องมีซับอังกฤษอยู่ก่อน)

---

## เริ่มใช้งาน

ไม่ต้องติดตั้ง dependency ใดๆ — โค้ดใช้ Python standard library ล้วน (ต้องมี Python 3.10+)

### ขั้นที่ 1 — ก๊อป transcript จาก Udemy

1. เปิดวิดีโอบทเรียน กดปุ่ม **Transcript** ข้างๆ ตัวเล่นวิดีโอ
2. เลือกข้อความทั้งหมดในแถบ transcript แล้ว `Ctrl+C`
3. วางลงไฟล์ `courses/<ชื่อคอร์ส>/<ชื่อบท>.txt`

เครื่องมืออ่านได้ทั้งรูปแบบที่ก๊อปจากแถบ transcript (มี timestamp `0:00` นำหน้า),
ไฟล์ `.srt`, ไฟล์ `.vtt` และข้อความล้วนไม่มีเวลา

### ขั้นที่ 2 — เตรียม

```bash
python -m udemy_th prepare courses/my-course/05-closures.txt
```

### ขั้นที่ 3 — แปล (เลือกทางใดทางหนึ่ง)

**ทาง 1: อัตโนมัติด้วย Antigravity CLI** — ไม่ต้องมี API key เหมาะกับการทำทั้งคอร์ส

```bash
python -m udemy_th translate work/my-course/05-closures
```

**ทาง 2: ให้ Claude Code แปล** — ฟรี คุมคุณภาพได้ดีที่สุด เหมาะกับบทสำคัญ

บอก Claude Code ในโปรเจกต์นี้ว่า:
> อ่าน `work/my-course/05-closures/translate-request.md` แล้วแปลตามที่ระบุในไฟล์

**ทาง 3: Claude API** — ต้องตั้ง `ANTHROPIC_API_KEY` ก่อน

```bash
python -m pip install -r requirements.txt
python -m udemy_th translate work/my-course/05-closures --engine claude
```

### ขั้นที่ 4 — สร้างไฟล์ผลลัพธ์

```bash
python -m udemy_th build work/my-course/05-closures
```

ได้ไฟล์ใน `out/my-course/05-closures/`:

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `05-closures.dual.srt` | ซับอังกฤษ+ไทย โหลดขึ้นวิดีโอ Udemy ได้ **(แนะนำ)** |
| `05-closures.th.srt` | ซับไทยอย่างเดียว |
| `05-closures.summary.md` | สรุปบทเรียน + อธิบายโค้ด + ศัพท์ในบทนี้ |

## คำสั่งทั้งหมด

```bash
python -m udemy_th prepare <ไฟล์ transcript>   # เตรียมไฟล์คำขอแปล
python -m udemy_th translate <โฟลเดอร์งาน>      # แปลอัตโนมัติ
python -m udemy_th build <โฟลเดอร์งาน>          # สร้าง .srt + สรุป + อัปเดตคลังศัพท์
python -m udemy_th glossary                     # ส่งออกคลังศัพท์เป็น Markdown
python -m udemy_th status                       # ดูว่าบทไหนแปลถึงไหนแล้ว
```

ตัวเลือกที่ใช้บ่อย:

| ตัวเลือก | ความหมาย |
|---|---|
| `prepare --title "ชื่อบท"` | ตั้งชื่อบทเรียนให้อ่านง่ายในไฟล์สรุป |
| `translate --effort low` | แปลเร็วขึ้น ใช้กับบทที่ไม่ยาก |
| `translate --engine claude` | ใช้ Claude API แทน Antigravity |
| `build --bom` | เขียน `.srt` แบบ UTF-8 with BOM (แก้ปัญหาไทยเพี้ยนใน VLC) |

## จุดเด่น: คลังศัพท์ทำให้คำแปลสม่ำเสมอทั้งคอร์ส

ทุกครั้งที่แปล ศัพท์เทคนิคที่เจอจะถูกเก็บลง `glossary/glossary.json`
แล้วบทเรียนถัดไปจะถูกป้อนคลังศัพท์นี้กลับเข้าไปก่อนแปล

ผลคือ `closure` ในบทที่ 40 ถูกแปลด้วยคำเดียวกับบทที่ 3 — ไม่ใช่คนละคำทุกบทแบบ Google Translate
และคุณได้คลังศัพท์ไว้ทบทวนก่อนสอบ/สัมภาษณ์เป็นของแถม

```bash
python -m udemy_th glossary --course "JavaScript Masterclass"
# -> glossary/glossary.md ตารางศัพท์ทั้งหมดพร้อมคำอธิบายไทย
```

## โครงสร้างโฟลเดอร์

```
courses/     transcript ต้นฉบับที่คุณก๊อปมาวาง
work/        ไฟล์ระหว่างทาง (คำขอแปล + คำแปลดิบ)
out/         ผลลัพธ์ที่เอาไปใช้จริง (.srt + สรุป)
glossary/    คลังศัพท์สะสมทั้งหมด
udemy_th/    ซอร์สโค้ด
docs/        คู่มือตั้งค่า extension
```

## หมายเหตุเรื่องลิขสิทธิ์

เครื่องมือนี้ประมวลผล transcript ของคอร์สที่ **คุณซื้อแล้ว** บนเครื่องคุณเอง
เพื่อให้คุณเข้าใจบทเรียนที่จ่ายเงินไปแล้ว ไฟล์ทั้งหมดอยู่ในเครื่อง ไม่ได้ส่งไปเผยแพร่ที่ไหน

สิ่งที่ไม่ควรทำ: แจกจ่ายไฟล์ซับหรือสรุปที่ได้ให้คนอื่น เพราะเนื้อหาบทเรียนเป็นลิขสิทธิ์ของผู้สอน
